### コンテナアダプタ std::stack
std::stackはLIFO(Last in, First out)なので、RPNの手法に合う

基本アルゴリズムはこんなかんじ：
```
for each token:
	if token is a number:
		stackにpushする
	
	else if token is an operator:
		stackから2つpopする
		計算する
		結果をpushする
```

やること
・RPN->std::stackを使用
・stackの不変条件の管理
	->演算子処理の時には少なくとも２つの値が必要
・入力が正しい式を検証できるか
	-> 最後にstackへ２個以上残っていたら式として不完全
・演算の境界条件を扱う
	-> 数字がふそく
	-> 最終結果が１つではない
	-> 0除算
	-> 不正な文字
	-> 演算子だけの入力
	-> 空文字列

```
(2, 6) (3, 8) (1, 9)
```

並べた大きい方と、先頭ペアの小さい方から主列をつくる
```
主列：　　2 6 8 9
挿入待ち: 3 1
```
2 <= 6 <= 8 <= 9なので主列はすでにソート済

3. 挿入待ちの要素を決められた順序で二分挿入する
- Jacobsthal数に基づいて、挿入する順番を決める

- 奇数個だった場合のあまりも、挿入対象に含めること

Jacobsthal数列
次 = 直前 + 2 * 2つ前

```
J0 = 0
J1 = 1

J2 = J1 + 2J0
   = 1  + 2*0

J3 = J2 + 2J1
   = 1 + 2*1
   = 3

J4 = J3 + 2J2
   = 5 + 2*1
   = 11

J5 = J4 + 2J3
   = 5 + 2*3
   = 11

J6 = J5 + 2J4
   = 11 + 2*5
   = 21

したがって
0, 1, 1, 3, 5, 11, 21, 43, 85...
```
